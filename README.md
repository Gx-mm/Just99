# 🛒 99Shops - The Complete Premium E-Commerce Platform

Welcome to **99Shops**, a ready-to-launch, fully functional e-commerce platform designed to deliver a top-tier shopping experience. This project isn't just a static template; it's a complete ecosystem featuring a real-time database, user authentication, and a unique in-built digital wallet system.

Whether you're looking for a solid foundation for a startup, a high-quality portfolio piece, or a complete e-commerce solution, 99Shops has everything built right in.

## 🚀 What You Get Out of the Box

### 1. 💎 Premium Shopping Experience (UI/UX)
* Fast, smooth, and professional interface inspired by top-tier e-commerce apps.
* Features Glassmorphism design, skeleton loading screens, and smooth interactive animations that give users a premium feel.

### 2. 💳 In-Built "Smart Wallet" System
* **No Payment Gateways Needed:** Users can top up their "Smart Balance" via QR code or UPI directly from their dashboard.
* **1-Click Checkout:** During checkout, users can seamlessly pay using their available Smart Balance for instant order confirmation.

### 3. 🛍️ "Window Shopping" (Guest Mode)
* **Open Browsing:** Anyone can visit the site and browse products, categories, and deals without needing an account.
* **Smart Authentication:** The moment a guest tries to add an item to the cart, wishlist a product, or open their profile, they are instantly redirected to the login page.

### 4. 🛒 Live Cart & Wishlist Management
* Users can save their favorite products to a dedicated Wishlist.
* The Cart features real-time price calculations, showing the Total MRP, Total Discount/Savings, and Final Price dynamically before checkout.

### 5. 📦 Complete Order Tracking
* A dedicated "My Orders" section where users can view their entire purchase history.
* Live status tracking with visual badges for every order state (*Pending, Processing, Shipped, Delivered, Cancelled*).

### 6. 👤 Personal User Dashboard
* A comprehensive account page tracking the user's total orders, delivered items, and returns.
* Seamless profile and delivery address management system built directly into the UI.
